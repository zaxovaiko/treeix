Everything around the diff, too

A group per agent

Each agent gets a group: its worktree, its terminal panes, its plan. A badge lights up the moment a session stops and waits for an answer, so a run never sits idle while you are looking somewhere else.

Claude Code and Codex in split panes, ⌘1 starts one where you are standing

Reviews that turn into prompts

Pull requests from GitHub and GitLab open with their threads intact. A reviewer's note becomes an agent task with one click, and the agent receives the file and the lines rather than a pasted wall of code.

Through the gh and glab CLIs you already signed in to

Tickets beside the branch

Jira work is grouped by whose move it is: yours, the reviewer's, or blocked. Open a ticket, start a worktree from it, and keep the Confluence spec next to the code it describes.

Both are plugins. Switch one off and its code stops loading.

A queue of comments, sent as one prompt

Write notes as you read. They stack in the drawer with the file and lines they belong to, then go to the session in that worktree as a single next prompt once you are done reading.

References only. Your code is never copied into the prompt.

Open source, top to bottom

Treeix ships under the Apache 2.0 licence. Read the code that talks to your repositories, build it yourself, or fork it. Nothing leaves your Mac either: Treeix shells out to git, gh, glab and your agent CLIs, and there is no account to sign in to.

Questions people ask first

Does my code leave my machine?

No. Treeix reads your repositories locally and runs the command line tools you already have: git for diffs, gh and glab for pull requests, claude and codex for sessions. There is no Treeix server.

Which agents does it work with?

Claude Code and Codex, each in its own terminal pane. A plain shell session works too, and Treeix still notices when a session is waiting for an answer.

Do I have to use git worktrees?

No. Any repository under your home folder shows up. Worktrees are how Treeix keeps one agent per branch without touching the checkout you are working in, so it makes them easy, but plain repositories are fine.

What do I need installed?

Git, plus whatever the features you use need: gh or glab for pull requests, claude or codex for agent sessions, acli for Jira and Confluence. Each one is optional and its feature stays quiet without it.

Which Macs does it run on?

Apple silicon, macOS 14 or later. The first launch needs Open Anyway under Privacy & Security, because the build is not notarised yet.

Is it really free?

Yes. Free to download, and the source is public under Apache 2.0. If it saves you an afternoon, open an issue with what you would fix next.
