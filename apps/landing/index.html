Your AI workspace.
Everything you use daily, in one app.

Treeix is a free, open source AI workspace for Mac and Linux. Agent terminals that outlive the window, worktrees, diffs, pull requests and tickets sit in one app. The notes you leave on the lines go back to the Claude Code or Codex session that wrote them.

to the agent that wrote the code.

  1. Pick a worktreeEvery repo and worktree in one sidebar, with a count of changed files.

  3. Send to the sessionComments go to the Claude Code or Codex session running in that worktree.

Behind the window

Quit Treeix. The agents keep going.

A daemon owns every session

Shells and agents run in treeix-ptyd, a background process, not in the window. Close Treeix, update it, open it again, and each session is still there with its scrollback. Sessions are grouped by repo and worktree in the sidebar, or sit in tabs along the top, and a dot on a Claude Code or Codex session says working, waiting for you or done.

Recursive splits, a quick terminal on a global shortcut, and a notification when an agent stops to ask

Routines run without you

Hand an agent a prompt and a trigger: a schedule, a GitHub or Jira event such as a review request or a failed CI run, or a call to a local webhook. It runs in the repo, in a fresh worktree or in the pull request's worktree, with a turn budget and the permissions you set. The daemon fires it, so it runs with Treeix closed.

Pick what a run leaves behind: local commits, a draft pull request, or a push to the pull request it worked on. Treeix commits, pushes and opens the pull request itself after a clean run, and later runs add to it while it is open. Routine pull requests have their own filter in the pull requests panel.

Agents never get push or pull request tools. Webhooks listen on 127.0.0.1 only

Around the diff

The ticket and the pull request are already open.

Your Jira and Notion tickets, one click from a worktree

Open worktree lists the Jira issues and Notion tasks assigned to you under Your tickets. Pick one and Treeix names the branch after it, creates the worktree, copies your .env files into it, and gives the agent the ticket's title, link and description as its first prompt.

Bugs get a fix/ branch, the rest feat/, both with the ticket key in front, so the ticket drops off the list once its branch exists.

Jira through acli, Notion through a personal access token. Both stay off until you switch them on in Settings

Pull requests next to the branch

The pull requests panel lists the GitHub pull requests and GitLab merge requests of every repo you have open. Check one out into a worktree, open it, merge it, and watch its CI checks without leaving the window. A red check can go straight to an agent.

Through the gh and glab CLIs you already signed in to

Notes stack up, then go over as one prompt

Write notes as you read. Each one keeps the file and the line range it came from, and they wait in the drawer until you send the whole stack to the session in that worktree as one prompt.

References only. Your code is never copied into the prompt.

A browser beside the terminal

Open the app your agent is building next to its session. The pane has a console and a network view, and an error can go to the agent in one click. Through Treeix's MCP server the agent can open pages, read them, click, type and take screenshots.

Built on the system WebView instead of Chromium. Agent control has its own switch in Settings.

Questions people ask first.

Does my code leave my machine?

Not through Treeix. It reads your repositories locally and runs the command line tools you already have: git for diffs, gh and glab for pull requests, claude and codex for sessions. There is no Treeix server. What you type into an agent goes to that agent's vendor, the same as in your own terminal.

Which AI agents does it work with?

Claude Code and Codex, in a terminal pane or as a chat beside it, with a status dot for working, waiting for you and done. Any other CLI agent runs in a plain shell session.

What happens when I quit Treeix?

Your shells and agent sessions keep running. A small background daemon, treeix-ptyd, owns them (a launchd agent on a Mac), so opening Treeix again reattaches each one with its scrollback. Routines run in the daemon too, so they fire with Treeix closed.

Do I have to use git worktrees?

No. A plain repository works, and so does a plain folder. Worktrees are how Treeix keeps one agent per branch without touching the checkout you're working in, so it makes them easy.

What do I need installed?

Git, plus whatever the features you use need: gh or glab for pull requests, claude or codex for agent sessions, acli for Jira, npx for the chat view. Notion takes a personal access token instead of a CLI. Each one is optional and its feature stays quiet without it.

Which systems does it run on?

macOS 13.3 or newer, as one build for Apple silicon and Intel, signed and notarized by Apple so it opens like any other app. On Linux there is an x86_64 AppImage on GitHub releases. Dictation and meeting recording need Apple silicon. Updates arrive through the built-in updater.

Is it free?

Yes. Free to download, and the source is public under Apache 2.0.
