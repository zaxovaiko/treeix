Privacy

Last updated 20 September 2026

What Treeix collects

Nothing. The app has no account, no server of its own and no analytics or crash reporting. It never phones home, including to check for updates on your behalf without asking.

What stays on your Mac

Your repositories, diffs, comments, terminal sessions, window layout and settings are read from and written to your own disk. Comments live next to the worktree they belong to, and the app's settings live in its application support folder.

Which connections the app makes

Treeix runs the command line tools you already have, under your own credentials, and only for the features you use:

  • git for repositories, worktrees and diffs. Local only.
  • gh and glab for pull requests and merge requests, talking to GitHub or GitLab as you.
  • claude and codex for agent sessions. Whatever you send in a session goes to that vendor under their terms, exactly as it would in your own terminal.
  • acli for Jira and Confluence, talking to your Atlassian site as you.
  • GitHub's release feed, to tell you when a newer Treeix exists.

Each of these is a plugin. Switch one off in Settings and its code stops loading, connections included.

This website

treeix.dyvertex.com is a static page hosted on Vercel, with no cookies and no analytics. Vercel writes its own server logs, which include your IP address and user agent, under Vercel's privacy policy. Downloads are served by GitHub Releases, under GitHub's privacy statement.
