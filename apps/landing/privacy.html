Privacy

Last updated 22 October 2026

What Treeix collects

Nothing. The app has no account, no server of its own and no analytics or crash reporting, and it sends nothing about you or your code to its authors. It does make a few requests of its own, such as the check for a newer version. Every one of them is listed below.

What stays on your computer

Treeix reads and writes your repositories, diffs, comments, terminal sessions, window layout and settings on your own disk. Comments live next to the worktree they belong to, and the app's settings live in its application support folder. Tokens you paste into Settings go into the system keyring. Audio for dictation and meeting recording is recognised on the Mac and never uploaded.

Which connections the app makes

Treeix runs the command line tools you already have, under your own credentials, and only for the features you use:

  • git for repositories, worktrees and diffs. Local only.
  • gh and glab for pull requests and merge requests, talking to GitHub or GitLab as you. Routines that wait for a GitHub event poll the same way, about once a minute.
  • claude and codex for agent sessions and the chat view. Whatever you send in a session goes to that vendor under their terms, exactly as it would in your own terminal.
  • acli for Jira, talking to your Atlassian site as you. Off until you switch Jira on.
  • Notion, at api.notion.com, with a personal access token you paste into Settings. Off until you switch Notion on.
  • npx, which fetches the Claude and Codex chat adapters from the npm registry the first time you open a chat.

Treeix also makes a few requests itself:

  • To check for updates, Treeix fetches a signed latest.json from GitHub releases on start, from the tray and from Settings > About. The update is checked against Treeix's public key before it installs. Turn off Check for updates on start in Settings > About and the app only looks when you ask.
  • The usage feature downloads a public price list from raw.githubusercontent.com at most once a day, to estimate cost. Offline, it keeps the last list.
  • The pull requests panel loads author pictures from github.com.
  • If you switch on dictation or meeting recording and pick a speech model, Treeix downloads it from Hugging Face. Only the download goes over the network, the audio never does.
  • The browser pane loads the sites you open, like any browser. The default search is Google, and Settings offers DuckDuckGo and Bing.

The MCP server and the routine webhooks listen on 127.0.0.1 only, and the background daemon talks to the app over a local socket, so nothing else on your network can reach them. Most features can be switched off in Settings. A feature that is off does no work, connections included.

This website

treeix.dyvertex.com is a static page hosted on Vercel, with no cookies and no analytics. Vercel writes its own server logs, which include your IP address and user agent, under Vercel's privacy policy. Downloads are served by GitHub Releases, under GitHub's privacy statement.
