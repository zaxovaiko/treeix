What a workspace holds

  • Projects (whole repos, optionally pinned worktrees)
  • Agent and shell sessions started inside those projects
  • Open PR and plan tabs, dock layout, selected worktree
  • Comments stay per worktree, so they follow automatically

Switching

  • ⌃1…⌃9 or ⌘K "Switch workspace" (⌘1-3 stay for tabs)
  • Sessions keep running in the background, badges show waiting agents
  • Sidebar, PR list, ⌘K files and usage scope to the workspace
  • "All projects" keeps today's behaviour

Open questions

  • Can a project live in two workspaces? (mock: yes)
  • Auto-create a workspace per project on first run, or start with one?
  • Rail (always visible, costs 60px) vs switcher (no space, one click deeper)
