What a branch row shows

  • Ahead/behind its upstream (↑2 ↓5), last commit age, PR badge when one is open
  • No uncommitted changes count: only worktrees have a working copy
  • Merged or gone-upstream branches dimmed, with "Delete merged" in the menu

Actions

  • Open as worktree (primary): git worktree add .claude/worktrees/<branch>, then selects it
  • View diff vs base without checking out (git diff main...branch), read-only like a PR
  • Checkout in main worktree, copy name, delete, open PR

Scope

  • Local branches by default, remote-only behind a toggle; sorted by last commit
  • Branches already checked out in a worktree are not repeated
  • Recommendation: A for everyday use, C as the ⌘K / "New worktree" flow; B only if lists get long
